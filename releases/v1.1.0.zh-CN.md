# 糯米 v1.1.0

给桌面添一点陪伴。糯米是一款免费的 Windows AI 桌面伙伴。

## 功能亮点

- 使用本地模型或在线 AI 聊天，也可以通过支持视觉的模型交流图片。
- 语音聊天，以及使用本地视觉模型的轮流式摄像头辅助通话。
- 专属信箱，收下欢迎信、日常小笺，也可以写信给未来的自己。
- 照片库、本地搜索与陪伴手账，留下日常的小小片段。
- 自定义名字、性格、主题，以及图片或 Live2D 形象。

## 开始使用

1. 下载 [Nuomi Setup 1.1.0.exe](https://github.com/Smart-Jason/nomi/releases/download/v1.1.0/Nuomi.Setup.1.1.0.exe)，运行安装程序。
2. 打开糯米，选择资源保存位置，下载基础模型和工具。
3. 点击 **Start Nuomi** 开始使用。界面默认英文，可在启动器或应用设置中切换中文。

**目前提供 Windows 版本，安装包约 200 MiB。** 首次启动需要额外下载模型和工具，请预留磁盘空间并保持联网。
