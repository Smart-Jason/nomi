# Nomi v1.1.0 — Windows Desktop Companion

A little company for your desktop. Nomi (糯米) is a free AI desktop companion with chat, voice, customizable appearance, and a personal Inbox.

**[Website](https://smart-jason.github.io/nomi/)** · **Windows installer:** `Nuomi Setup 1.1.0.exe` · **Size:** 200 MiB (209,659,274 bytes)

## What's included

- A desktop pet, quick chat, and a phone-style home screen with English and Chinese interfaces.
- Text chat and image messages with a compatible model; local models through llama.cpp or supported online AI providers using your own API credentials.
- Speech recognition and spoken replies, with configurable local and online voice services.
- Camera-assisted, turn-based calls with a local vision model.
- An Inbox for welcome letters, daily notes, scheduled letters to your future self, and optional check-ins.
- A photo library, local search, and a companion journal with calendar and activity records.
- Customizable names, personality, appearance, and themes, including image and Live2D appearance options.

## Getting started

1. Under **Assets**, download **Nuomi Setup 1.1.0.exe** and run the installer.
2. Open Nomi and choose a resource folder in the first-launch setup screen.
3. Download the required models and tools, then select **Start Nuomi**. These resources are additional to the installer; allow extra disk space and download time. Downloads require access to sources including Hugging Face and GitHub.
4. Start chatting with the local model, or configure a supported online provider with your own API key.

New profiles start in English. Choose Chinese in the launcher or app settings if preferred. Spoken replies are enabled by default through Edge TTS, which needs an internet connection; you can change or disable speech in the voice settings. Online AI providers may charge for usage. Local performance depends on your hardware and model selection.

## Current limitations

- Windows only.
- Memory management and the plugin store are still in development. Chat history, Inbox, and journal features are separate from long-term memory.
- Coze chat is temporarily unavailable.
- Camera-assisted calls currently require a local vision model; online video calls are not available.

Live2D components, models, fonts, and other third-party resources remain subject to their respective licenses. User-imported models are not included in this download.

## 中文说明

糯米是一款免费的 Windows AI 桌面伙伴，可以聊天、语音交流、定制形象，也能通过信箱留下日常的小小陪伴。

### 本版内容

- 桌面宠物、快捷聊天和手机式主界面，支持中英文。
- 文字聊天与图片消息；图片理解需要支持视觉的模型。支持 llama.cpp 本地模型，以及使用自备 API 密钥的在线服务。
- 语音识别与语音回复，可选择本地或在线语音方案。
- 使用本地视觉模型的轮流式摄像头辅助通话。
- 欢迎信、日常小笺、写给未来自己的定时信，以及主动设置的关心提醒。
- 照片库、本地搜索，以及带日历和活动记录的陪伴手账。
- 名字、性格、外观与主题自定义，支持图片和 Live2D 形象。

### 下载与首次使用

1. 在本页 **Assets** 中下载 **Nuomi Setup 1.1.0.exe**，运行安装程序。
2. 打开糯米，在首次启动界面选择资源保存位置。
3. 下载所需模型和工具后，点击启动。安装包约 **200 MiB**，模型和工具需要额外下载，请预留磁盘空间和下载时间；资源下载需要能够访问 Hugging Face、GitHub 等来源。
4. 使用本地模型开始聊天，或在设置中配置支持的在线服务及自己的 API 密钥。

新用户默认使用英文，可在启动器或应用设置中切换中文。语音回复默认开启并使用需要联网的 Edge TTS，可在语音设置中更换或关闭。外部 AI 服务可能另行收费，本地运行表现取决于硬件和模型。

### 当前限制

- 目前仅支持 Windows。
- 记忆管理和插件商城仍在开发中；聊天记录、信箱与陪伴手账不依赖长期记忆功能。
- Coze 聊天暂不可用。
- 摄像头辅助通话目前仅支持本地视觉模型，暂不支持在线视频通话。

Live2D 组件、模型、字体及其他第三方资源遵循各自许可。安装包不包含用户自行导入的模型。

附件 `SHA256SUMS.txt` 可用于核对安装包。GitHub 自动生成的 **Source code** 压缩包是网站仓库内容，不是桌宠应用源码；安装糯米请选择 `.exe` 文件。
