# Nomi

A bilingual product showcase for Nomi, an AI companion for the Windows desktop.

**Website:** https://smart-jason.github.io/nomi/

## Website source

- `index.html`: page content and structure
- `styles.css`: responsive layout
- `site.js`: English/Chinese switching and illustrative feature previews
- `assets/`: website artwork, icon, and Nunito font

This repository contains the showcase website. The interactive feature previews use sample content.
