# Nomi

A bilingual product website for Nomi, a free AI companion for the Windows desktop.

**Website:** https://smart-jason.github.io/nomi/

**[Download Nomi v1.1.0 for Windows](https://github.com/Smart-Jason/nomi/releases/tag/v1.1.0)**

Choose `Nuomi Setup 1.1.0.exe` under Assets. The installer is about 200 MiB; first launch downloads additional models and tools. See the [bilingual release notes](releases/v1.1.0.md) for setup instructions and current limitations.

## Website source

- `index.html`: page content and structure
- `styles.css`: responsive layout
- `site.js`: English/Chinese switching and illustrative feature previews
- `assets/`: website artwork, icon, and Nunito font

This repository contains the product website. The interactive feature previews use sample content. Desktop installers are distributed through GitHub Releases; the desktop application source is not included in this repository.
